# Nico2 Phone - SillyTavern 手机组件扩展

SillyTavern 聊天窗口内嵌手机组件扩展，支持完整的微信风格交互。

## 功能特性

### 聊天界面
- 左右双气泡对话，支持文字、图片、语音、转账、礼物、外卖、定位、链接、音乐卡片等
- 消息长按操作面板：引用回复、撤回、删除
- 系统消息毛玻璃胶囊样式
- 语音消息气泡（支持播放动画和文字展开）
- 引用回复消息

### 通话功能
- 语音/视频通话界面
- 来电铃声、通话计时、最小化悬浮窗
- 通话中实时消息气泡

### 朋友圈
- 动态发布（文字/图片/文字图）
- 点赞、评论、删除动态
- 点击头像和封面可上传本地图片（localStorage 缓存）

### 情侣空间
- 情侣关系天数显示
- 待办清单、纪念日、相册
- 个性签名编辑

### 个性化设置
- 毛玻璃/纯实色风格切换
- 头像圆形/方形切换
- 全局颜色自定义（外壳、头部、气泡、文字等）
- 左侧气泡文字颜色单独调节
- 手机背景图本地上传

### 其他
- 便签贴纸（可编辑，同步指令）
- 自定义表情包
- 骰子、猜拳、戳一戳互动
- 拨号盘、通讯录、通话记录
- 所有操作自动生成指令并粘贴到酒馆输入框

## 安装方法

1. 将 `nico2-phone` 文件夹放入 SillyTavern 的 `data/default-user/extensions/` 目录
2. 重启 SillyTavern
3. 在扩展管理中启用 `Nico2 Phone Extension`
4. 硬刷新页面（Ctrl+Shift+R）

### 支持的消息指令格式

| 格式 | 说明 |
|------|------|
| `L\|文字\|时间` | 左侧普通消息 |
| `R\|文字\|时间` | 右侧普通消息 |
| `R-BLK\|文字\|时间` | 被拉黑拒收 |
| `[撤回:内容]` | 撤回消息 |
| `[引用:原文] 回复内容` | 引用回复 |
| `[呼叫:语音通话/视频通话]` | 发起通话 |
| `[接听通话]` / `[挂断通话]` | 接听/挂断 |
| `[通话:内容]` / `[视频:内容]` | 通话中消息 |
| `[语音:时长"|转文字]` | 语音消息 |
| `[转账:金额:说明]` | 转账 |
| `[收款:金额]` / `[退回:金额]` | 收款/退回 |
| `[礼物:金额|名称|备注]` | 礼物 |
| `[外卖订单:店铺|内容|地址]` | 外卖 |
| `[定位分享:位置|距离]` | 定位 |
| `[链接分享:标题|URL]` | 链接 |
| `[听歌邀请:歌曲名]` | 音乐邀请 |
| `[拍一拍:内容]` | 拍一拍 |
| `[戳一戳:内容]` / `[摇骰子:点数]` / `[猜拳:结果]` | 互动 |
| `[图:URL|描述]` | 图片 |
| `[文图:内容]` | 文字图片 |
| `[情侣空间卡片:内容]` | 情侣空间 |
| `$[更新便签:内容]` | 更新便签 |

## 技术说明

- 扩展通过 MutationObserver 监听 DOM，自动识别 `<phone>` 标签并渲染
- 手机组件渲染在 iframe 内，扩展通过定时扫描 iframe 初始化交互
- 所有颜色、背景、便签等设置保存在 localStorage
- 类名统一使用 `Nico-` 前缀
